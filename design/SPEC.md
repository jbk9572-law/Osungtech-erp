# 디자인 규칙표 (SPEC) — 시안 HTML이 정답이다

**원본**: `design/mockups/type-A~H2.html` (사용자 승인 시안, 좌측 메뉴는 B안 208px로 반영).
**수치 원본**: `design/spec.json`, `design/spec-parts.json` (시안을 브라우저로 열어 잰 값. 시안을 고치면 다시 잰다).
**이 표가 코드의 기준이다.** 화면은 이 표의 값만 쓴다. 표에 없는 값을 쓰려면 먼저 이 표를 바꾸고 사용자 승인을 받는다.

시안끼리 값이 조금씩 달랐던 곳(버튼 26/30, 모서리 5/6/8/12 등)은 아래 "규칙값"으로 한 가지로 정리했다.

## 7. 블록 규칙 (내용을 어떻게 묶는가)

1. **입력 블록**: 입력칸 묶음은 항상 박스(카드) 하나로 감싼다. 제목(카드 머리) + 12칸 격자 + 그 블록의 버튼 한 줄.
2. **힌트·안내**: 입력 박스 안쪽 맨 아래 또는 카드 머리 옆 작은 글자 한 종류만 쓴다.
3. **요약·합계 블록**: 숫자 합계는 항상 요약 박스(카드 8px, 칸 구분선)로 보여준다. 맨텍스트로 두지 않는다.
4. **버튼 위치**: 그 블록의 동작 버튼은 그 블록 안 오른쪽 아래. 화면 전체 동작은 도구 줄.
5. **상세 패널**: 제목줄(제목 + 상태 칩) → 키-값 → 합계 박스 → 표 → 하단 버튼. 갈색·강조 윗줄·막대 제목 없음.
6. **좌측 메뉴**: 208px, 항목 13px, 그룹 이름 11.5px, 선택 항목은 왼쪽 3px 파란 막대 + 연한 파랑 배경.

## 8. 검사 방법

- `design/spec.json`의 수치와 실제 앱 화면의 수치를 CI(실제 글꼴·실제 앱)에서 재서 비교한다.
- 규칙값에서 벗어난 부품은 목록으로 보고하고, 사용자가 확인한 뒤 고친다.

## 9. 키보드 규칙 (결정: 엑셀과 같게)

- **표(그리드) 안**: F2 = 셀 편집(엑셀과 동일). 신규는 도구 줄 버튼 또는 Ctrl+Enter.
- 이동: 방향키, Tab/Shift+Tab, Enter(아래)/Shift+Enter(위), Home/End, Ctrl+방향키, PageUp/PageDown.
- 선택: Shift+방향키, Ctrl+A, Shift+Space(행), Ctrl+Space(열).
- 편집: Esc 취소, Delete 지우기, Alt+Enter 줄바꿈. 복사·붙여넣기: Ctrl+C/X/V(여러 셀 붙여넣기 포함), Ctrl+D(아래로 채우기), Ctrl+R(오른쪽).
- 입력 보조: Ctrl+;(오늘 날짜), Alt+=(합계). 실행취소 Ctrl+Z/Y. 찾기 Ctrl+F. 저장 F7 또는 Ctrl+S. 조회 F5. 닫기 Esc.
- 브라우저가 가로채는 키(Ctrl+N/T/W)는 쓰지 않는다.

## 10. 입력 표 규칙 (결정: 엑셀식)

- 전표·입력 표는 맨 아래에 항상 빈 줄 하나를 유지한다. 거기에 글자를 입력하면 줄이 확정되고 새 빈 줄이 생긴다. "+ 품목 추가" 버튼은 두지 않는다.
- 빈 줄은 합계·검증·저장에서 제외한다. 모바일은 맨 아래 빈 카드 하나로 대신한다.

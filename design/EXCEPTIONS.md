# 예외 변형 목록 (EXCEPTIONS)

규칙표(SPEC.md)에서 벗어나는 모양은 **이름 있는 변형**으로만 허용한다. 새 변형은 사용자 승인이 필요하다(기존 변형을 다시 쓰는 것은 승인 불필요).
변형도 글자·색·여백은 규칙표 값을 그대로 쓰고, 바뀌는 것은 아래 "바뀌는 값"뿐이다.

| 변형 | 바뀌는 값 | 이유 | 쓰는 곳 | 승인 |
|---|---|---|---|---|
| `stock-bar-row` | 표 행 높이 26px → 최대 31px | 재고 수준 막대(4px)가 재고수량 칸 안에 들어가 행이 커진다. 막대는 부족 재고를 한눈에 보게 하는 기능이라 유지한다 | 재고현황 표(`.erp-stock-bar`가 있는 행) | 2026-11-23 사용자("추천대로") |
| `wide-voucher-grid` | 표·입력 폼 폭 규칙 면제 | 매입·매출 전표는 열이 많아 넓은 폭이 필요하다 | 매출·매입 전표 표·입력 | 2026-11-23 사용자 |
| `wide-input-form` | 입력 폼 폭 규칙 면제 | 모조지 계산 등 칸이 많은 입력 화면 | 모조지 계산 | 2026-11-23 사용자 |
| `messenger-split` | 화면 종류 B형(필터 열 + 목록 + 상세 3분할) → 2열(목록 300px + 대화) | 메신저는 대화가 중심이라 필터 열이 비어 휑해 보였다. 필터는 목록 위 칩 한 줄로 옮긴다 | 메신저(모던) | **승인 대기(2026-11-23 제안)** — 사용자 확인 전에는 병합하지 않는다 |

## 규칙

1. 예외는 이 목록에 있어야 쓸 수 있다. 목록에 없는 예외는 `style` 직접 지정이 아니라 새 변형으로 제안한다.
2. 변형 수에는 상한을 둔다(지금 3개, 늘리려면 사용자 승인).
3. 급한 임시 예외는 기한(2주)을 붙여 이 표에 올리고 정식 등록하거나 없앤다.
